Privacy Policy — Daily Korea Uploader

Last updated: October 20, 2026

What this app is

Daily Korea Uploader is a private, single-user tool. It is used only by the owner of the YouTube channel Daily Korea to upload that channel's own videos. It is not offered to the public.

Google user data we access

  • YouTube upload (youtube.upload): to upload videos and set their title, description, tags and publish time on the owner's channel.
  • YouTube read-only (youtube.readonly): to confirm which channel is signed in and to check the status of uploaded videos.

How the data is used and stored

The OAuth token is stored only on the channel owner's own computer and is used only to perform the actions above. No Google user data is sold, shared with third parties, used for advertising, or transferred to any server operated by this app.

Limited Use

Daily Korea Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This app also uses YouTube API Services; see the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
